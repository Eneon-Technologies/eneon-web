Case study · Hardware · Embedded

SafeGuard LPG

A gas monitoring and alarm system that watches for LPG leaks, smoke and abnormal temperature, raises the right alarm for each event — and learns its environment to reduce false alarms over time.

Client
Syntec Limited
Disciplines
Hardware · Embedded systems
Monitors
LPG · Smoke · Temperature
Interface
Touchscreen · Status LEDs · Buzzer

The project

Safety alarms people can trust.

SafeGuard LPG continuously monitors gas level, smoke and temperature, and triggers an alarm that corresponds to the event it detects — so a gas leak, a fire risk and overheating are each clearly identified.

An alarm that sounds too often is easy to ignore. SafeGuard LPG uses an adaptive learning mechanism that learns the normal conditions of its environment, reducing false triggers over time while staying responsive to real hazards.

  • LPG leak detection

    Continuous gas-level monitoring for liquefied petroleum gas.

  • Smoke detection

    Early warning of smoke in the monitored space.

  • Temperature monitoring

    Detects abnormal heat before it becomes dangerous.

  • Event-specific alarms

    A distinct alarm for each type of hazard.

  • Adaptive learning

    Fewer false triggers the longer it runs.

  • Built-in self-test

    Checks its status LEDs, buzzer and sensors from the touchscreen.

How it works

Sense. Assess. Alert. Learn.

  1. 01

    Sense

    Gas, smoke and temperature sensors are read continuously.

  2. 02

    Assess

    Readings are evaluated against what is normal for that environment.

  3. 03

    Alert

    A real hazard triggers the alarm that matches the event.

  4. 04

    Learn

    The system adapts over time, cutting false triggers.
