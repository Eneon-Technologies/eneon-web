# Future product detail pages

When Eneon has a product ready to publish, add a product card using the template in
`pages/products.html` (images from Cloudinary). For a dedicated page, add a source body in
`pages/` and a row in `pages/site-map.tsv`, then rebuild.

Recommended sections: hero, media gallery, overview, features, specifications, applications,
documentation/downloads, support and a clear availability status. Only publish verified
product information.
