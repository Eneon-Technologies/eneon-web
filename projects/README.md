# Adding an approved project

1. Add optimized images to images/projects and optional MP4/WebM files to videos/projects.
2. Add an HTML project card in pages/projects.html with a real description, categories,
   status and accessibility text.
3. Give its media button data-lightbox-media, data-lightbox-type (image or video)
   and data-lightbox-title attributes.
4. For a public detail page, add a source body and a manifest entry, then run the build.

Only publish client names, project details and media after appropriate approval.
